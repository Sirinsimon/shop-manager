# 🚀 Quick Start Guide

## Getting Started in 3 Steps

### Step 1: Access the Application
Open your browser and navigate to your app URL (e.g., `http://localhost:3000`)

### Step 2: Choose Your Path

#### Path A: Create Your Own Account (Recommended)
1. Click **"Sign up"** on the login page
2. Fill in:
   - Username (min 3 characters)
   - Email address
   - Password (min 6 characters)
   - Confirm password
3. Click **"Create Account"**
4. ✅ You're in! Start managing your shop

#### Path B: Use Default Admin
1. Enter username: `admin`
2. Enter password: `admin123`
3. Click **"Sign In"**
4. ✅ You're in! Start managing your shop

### Step 3: Explore the Dashboard
- **Dashboard**: View overview and quick stats
- **Products**: Add and manage inventory
- **Sales**: Record transactions
- **Analytics**: View detailed reports

## 💡 Quick Tips

1. **First Time?** Create your own account for a personalized experience
2. **Testing?** Use the admin account for quick access
3. **Forgot Password?** Currently no reset - use admin account or create new one
4. **Multiple Users?** Each person can create their own account
5. **Logout?** Click the logout button in the top-right corner

## 🎯 Common Tasks

### Record a Sale
1. Go to **Sales** tab
2. Click **"Record Sale"**
3. Select product, quantity, and price
4. Click **"Record Sale"**

### Add a Product
1. Go to **Products** tab
2. Click **"Add Product"**
3. Fill in product details
4. Click **"Save Product"**

### Generate Report
1. Click **"Generate Report"** in header
2. PDF downloads automatically
3. Contains inventory, sales, and profit data

### Switch Theme
1. Click the sun/moon icon in header
2. Toggles between light and dark mode
3. Preference is saved automatically

## 🆘 Need Help?

### Can't Login?
- Check username and password
- Try admin account: `admin/admin123`
- Clear browser cache and try again

### Can't Signup?
- Username must be unique (3+ characters)
- Email must be valid and unique
- Password must be 6+ characters
- Passwords must match

### Something Not Working?
- Refresh the page
- Check browser console for errors
- Restart the development server
- Check documentation files
