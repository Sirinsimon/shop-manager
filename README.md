A full-stack e-commerce management platform for managing products, orders, customers, inventory, and sales through a modern admin dashboard.

Overview

Shop Manager is designed for small and medium-sized businesses to simplify daily store operations. It provides a centralized system where administrators can manage products, track inventory, process customer orders, and monitor business performance in real time.

Features

User authentication and secure admin login

Product and category management

Inventory and stock tracking

Customer management

Order processing and status updates

Sales dashboard with analytics

Responsive design for desktop and mobile

Payment integration support
